HTML · CSS · Netlify Forms

A single-page site for an independent massage and holistic health practice, designed and built end to end — custom typography, a logo prepared and embedded directly in the page, and a working contact form wired up through Netlify Forms so the client gets inquiries straight to their inbox with no backend to maintain.

Cascade CMS · Vanilla JavaScript · CSV as data source

A webpage built to showcase books written by Northwestern alumni authors, along with information about each one. Built in Cascade CMS with vanilla JavaScript, using a CSV file as a lightweight stand-in for a database — with results that are searchable, filterable, and sortable.

  • Searchable, filterable, sortable results
  • CSV-driven data with no backend required

Northwestern Donor Honor Roll

Cascade CMS · Vanilla JavaScript · CSV as data source

A full redesign and rebuild of the University's Donor Honor Roll, entrusted to me by the Giving team as a key project for annual donor recognition. Built in Cascade CMS with vanilla JavaScript and a CSV file standing in as the data source, listing donors alongside their level of giving with a clarity and elegance meant to properly showcase supporters' generosity.

  • Commissioned directly by the Giving team
  • Redesign of an existing, high-visibility page

Homecoming and Reunion Weekend Schedule

Cascade CMS · Vanilla JavaScript · CSV as data source

A redesign of the Homecoming and Reunion Weekend schedule, focused on usability for the team maintaining it as much as for the alumni reading it. Built in Cascade CMS with vanilla JavaScript and a CSV file as the data source, listing all weekend activity with results sortable and filterable by event type, and built so the schedule can be edited and updated swiftly during a weekend where timing changes fast.

  • Built for fast, low-friction editing by the team
  • Sortable and filterable by event type
